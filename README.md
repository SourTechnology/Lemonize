# Sour Technology, LLC
Welcome to the Sour Technology, LLC repository.
About
Sour Technology, LLC builds digital products and tools. This repository contains the POP! project, a link-in-bio site where users can create a profile, add links, and preview a personalized page.
POP!
POP! includes:

Sign-up and login screens
A profile editor for a POP Domain name and bio
Add and remove links
A live page preview
A responsive single-file HTML, CSS, and JavaScript implementation

# Getting started

Save the POP! website code as index.html.
Open the file in a modern web browser.
Create an account and customize your page.

Demo limitations
This is a front-end demo. Account and page data are stored in the browser’s localStorage; passwords are not securely protected. Do not use real credentials. POP Domain names are previews, not registered domains.
Production use
Before deploying publicly, implement secure server-side authentication, protected data storage, input validation, and hosting. Review any applicable privacy, security, and legal requirements.
